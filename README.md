# Office Artifacts: The One-Line Placard Contest

A program that writes a single museum placard line for an ordinary office
object, treated as an ancient artifact from a lost civilisation. One line,
at most 180 characters — the whole joke has to land in it.

The placard: a stapler, recast as a ritual binding object, with a catalogue
date, a material and a donor.

> Stapler, c. 1997. Pressed steel. Bound two sheets in eternal union; divorce required the removal tool. Gift of the Accounts Department.

Run it with Node 22: `main.ts` writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.
